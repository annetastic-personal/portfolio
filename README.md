# Anne Odom — Portfolio

A personal portfolio site presenting my full-stack web and application development work.

## About

This site showcases selected projects, my skills, professional background, and a downloadable resume. My work focuses on practical, human-centered tools for research, operations, and decision-making.

## Projects

### TTGCollector

A full-stack board-game collection manager (PostgreSQL, Express, React, Node) for cataloging games, pulling details from BoardGameGeek, and filtering a collection to decide what to play next.

### Pest Degree Day Calculator

An ASP.NET application backed by Microsoft SQL Server that helps Illinois farmers interpret historical pest activity and make better-informed decisions about future pest conditions.
